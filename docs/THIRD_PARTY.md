# Third-party components

Cutlery is original application code. It does not contain CapCut assets, templates, branding, private protocols or proprietary models. No application-wide distribution licence has been selected for this private project.

| Component | Use | Distribution notes / upstream source |
|---|---|---|
| Qt 6.8.3 (Core, Gui, Quick, QuickControls2, Multimedia, supporting modules) | Dynamically loaded UI/playback runtime | LGPL/GPL/commercial licensing varies by module and bundled dependency. This build uses public SDK modules; preserve notices and replacement/relinking rights. [Qt source archive](https://download.qt.io/archive/qt/6.8/6.8.3/single/) and [Qt licensing](https://doc.qt.io/qt-6/licensing.html). |
| FFmpeg n8.1.3-6-gff48edd8b2, BtbN Windows LGPL shared build | Separate ffmpeg/ffprobe child processes and their DLLs | Pinned archive/hash in `tools/Get-FFmpeg.ps1`; rejects GPL/nonfree build flags. [FFmpeg source](https://github.com/FFmpeg/FFmpeg/commit/ff48edd8b2), [build recipes](https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-09-28-13-06), [licensing](https://ffmpeg.org/legal.html). Codec patent questions are separate from software licences. |
| Qt Multimedia | Viewer surface and audio output for live playback | Deployed by windeployqt; decoding is done by the separate FFmpeg processes. Keep Qt's dependency notices/SBOM. |
| Microsoft C/C++ runtime | Windows runtime | Deployed by windeployqt from the build environment, subject to Microsoft's redistributable terms. |
| ONNX Runtime 1.22.0 with DirectML provider | `onnxruntime.dll`, loaded only by the separate `cutlery-ai.exe` worker | MIT. | DirectML 1.15.4 | `DirectML.dll`, GPU inference for the AI worker | Microsoft redistributable; licence in `licenses/onnxruntime`. Pinned NuGet package/hash. |

| Piper 2023.11.14-2 Windows release (AI pack only) | `tts/piper.exe`, a separate process for text to speech, with piper-phonemize, ONNX Runtime 1.14.1 and eSpeak NG (`espeak-ng.dll`, `espeak-ng-data`) | Piper and piper-phonemize MIT, ONNX Runtime MIT, eSpeak NG GPL-3.0-or-later (run only inside the separate Piper process; corresponding source: [rhasspy/espeak-ng](https://github.com/rhasspy/espeak-ng)). | Piper voice Thorsten (medium), German (AI pack only) | Voice for text to speech | Thorsten-Voice dataset CC0 ([Thorsten-Voice](https://github.com/thorstenMueller/Thorsten-Voice)); model from the pinned v1.0.0 release of [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices), pinned by hash in `tools/Get-Models.ps1`; its model card ships beside it. |
| U²-Net human segmentation model (AI pack only) | Person matte for AI background removal | Apache-2.0 ([U-2-Net](https://github.com/xuebinqin/U-2-Net)); ONNX export from the [rembg release](https://github.com/danielgatis/rembg/releases/tag/v0.0.0), pinned by hash in `tools/Get-Models.ps1`. | Whisper large-v3-turbo q5_0 (AI pack only) | Speech recognition model for automatic captions | MIT (OpenAI, [whisper](https://github.com/openai/whisper)); whisper.cpp format from the [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp) model repository, pinned by the SHA-1 whisper.cpp publishes. |
| MediaPipe face detection, Face Mesh and Iris Landmark models (AI pack only) | Face, eye and iris landmarks for eye contact | Apache-2.0 ([MediaPipe](https://github.com/google-ai-edge/mediapipe)). | Elements SFX by Crafter Station (five files) | Recorded mouse click, keyboard typing and three whooshes in the sound effects library (`sounds/`) | Stated as CC0 by the collection ([crafter-station/elements](https://github.com/crafter-station/elements), code MIT); the original recordists are not named. | System fonts | User titles/captions | Rasterized at render time. No font files are bundled. |

The portable pack includes upstream FFmpeg distribution notices/docs, available Qt SBOM data, licence texts in `licenses`, and a build manifest. This is an inventory, not a completed legal audit or a patent licence. Before public redistribution, audit the actual packaged DLLs, retain all applicable notices and corresponding-source obligations, and decide the application's own licence. The application package contains no model weights; the optional AI pack contains the U²-Net, Real-ESRGAN, Whisper, Silero VAD, MediaPipe and Piper voice models listed above, and Piper with eSpeak NG.
